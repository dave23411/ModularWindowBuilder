# Modular Window Builder – Unity Editor Tool

A professional Unity Editor extension for building scalable, prefab-based windows with real-world measurements, subdivision control, and per-panel configuration.

## Features
- Editor-only tool, no runtime code
- Vertical + horizontal subdivisions
- Fixed, TopHung, and SideHung panels
- Measurement Mode for in-scene sizing
- UI Toolkit interface with live previews
- Prefab-based construction workflow

## Requirements
- Unity 2021.3 LTS or Unity 6+
- Works with Built-in, URP, and HDRP

## Coming Soon
- Door support (Hinge, Pivot, Slider)
- Low Poly Mode with scalable primitive profiles
